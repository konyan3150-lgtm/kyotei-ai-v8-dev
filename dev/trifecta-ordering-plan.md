# 案3：3連単の組み立て補正（定義を実装前に固定、2026-10-23）

## なぜ順位が変わるのか
- 今の120通りの確率は q(i,j,k) ∝ p1(i)·p2(j)·p3(k)（艇ごとの1着・2着・3着の確率の積を正規化）。120通り全体に同じ単調変換（温度・Platt・isotonic）をかけて再正規化しても、同順位の扱いを除いて**順位は変わらず、上位6点も変わらない**
- 順位を変えるには、組み立て方そのものを変える必要がある。次の2つを候補として固定する
  - **A. 着順ごとの指数補正**：q_A(i,j,k) ∝ p1(i)^a · p2(j)^b · p3(k)^c。a,b,c は各評価日より前のデータだけで最尤推定（範囲 0.25〜4、各評価日で当てはめ直し）。a,b,c が等しくない限り、1着・2着・3着の重みが変わり順位が変わる
  - **B. Harville（1着確率だけから組み立て）**：q_B(i,j,k) = p1(i)·p1(j)/(1−p1(i))·p1(k)/(1−p1(i)−p1(j))。当てはめるパラメータなし（固定）
- p1・p2・p3 は保存済みの rank_probabilities（締切前の最後の有効スナップショット）だけを使う

## 比べる6点
- 基準1：保存済みの baseline_picks（本番と同じ makeBets：確率の0.68乗＋人気薄への加点）
- 基準2：基準の分布 q の上位6点
- 補正：q_A・q_B それぞれの上位6点
- 同順位は組番号の順

## 評価（同じレース、各評価日より前のデータだけで学習）
- 対象：修復済みシャドーの確定レース、**最初の20日（10/03〜10/22）の中だけ**。それより後は凍結済みの前向き検証の評価期間なので、学習にも方式の選択にも使わない
- 前日までが300R以上ある日から評価（ウォークフォワード）
- 指標：LogLoss、6点セットの校正（予測の合計と実際の的中率）、6点の的中率、**買い目の変更数**（基準と比べて入れ替わった券の数）、**基準だけ的中／補正だけ的中**の件数（基準1・基準2それぞれと比べる）、日別の差
- 採用の判断はしない。改善が見えた場合は、別途前向き検証を事前登録する
