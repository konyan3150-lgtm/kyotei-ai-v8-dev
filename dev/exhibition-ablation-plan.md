# 案5の追加比較：現行の展示寄与の分離（実装・結果確認の前に固定、2026-10-24）

PR #50（exhibition-correction-v1）の結果を見た後の追加探索。#50 の定義・係数・特徴は変えない。dev 限定、本番変更なし・採用保留。

## 比較する3つ（同じレース・同じ締切前スナップショット）
- ① 現行モデル：保存済み rank_probabilities（= 保存済み baseline_distribution）
- ② 展示計測値の寄与を無効化した現行モデル：凍結エンジン（live 8286a978 の scripts/update_server_predictions.mjs）では、展示タイム・展示ST・一周・まわり足・直線は exhibitionFactors（艇ごとの掛け算、0.94〜1.06）だけで確率に入る（コードで確認：featureArray の start_timing は選手の平均ST）。そこで p②_m(i) = p①_m(i) / ef(i)。ef はスナップショットの input_state.exhibition から、エンジンの exhibitionScores / exhibitionFactors をそのまま写した関数で計算
  - 進入コース・チルト・風は modelProbs・courseFactors・liveFactor にも入っていて、保存データだけでは外せない。②では残す（＝②は「展示計測値」だけを外したもの）
- ③ #50 の補正モデル（exhibition-correction-v1、係数は各評価日より前のデータだけで推定済みのもの、変更なし）。αで元の確率の鋭さも変えるので、①との差を展示特徴だけの効果とは解釈しない

## 6点
- 主：各分布の確率上位6点（同点は組番順）
- 副：エンジンの makeBets（hit モード）。①は保存済み baseline_picks、②は p② を同じ関数（写し）に通したもの。写しの makeBets が①で保存済み baseline_picks を再現することを実データで確認し、再現できないレースは件数を報告して副比較から外す

## 取得時刻の証跡（区別して記録）
