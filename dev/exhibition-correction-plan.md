# 案5：展示データの効きを強める補正（実装前に固定、2026-10-24）

## 目的
今のモデルは展示（展示タイム・展示ST・一周・まわり足・直線・進入）を手で決めた重みで使っている。締切前の展示後スナップショットで決め直しても6点はほぼ変わらなかった（PICK_TIMING_REPORT）。展示の効きをデータから学習して強めると、6点の的中率が上がるかを調べる。採用の判断はしない。本番は変更しない。

## データ
- シャドー `expert-shadow-official-v1`（dev/expert-shadow-repaired-archive）。除外・中止・未確定は使わない
- 各レースの「締切前に保存された最後の有効スナップショット」（validSnapshot、saved_at < 締切）。展示はそのスナップショットの input_state.exhibition だけを使う（締切後の情報は使わない）
- 対象：暦で固定した 10/03〜10/22。そのうち 6艇すべての展示タイムがあるレースだけ（hasExhibition）。展示なしのレースは件数だけ報告
- 前日までの対象レースが 300R 以上の日から評価

## 特徴（各レース内で計算、艇ごと）
- 展示タイム・展示ST・一周・まわり足・直線：レース内で平均0・標準偏差1に標準化し、符号を反転（小さいほど良い → 大きいほど良い）。欠測や全艇同値は0
- 進入：枠番と進入コースの差（進入コース − 枠番）。欠測は0

## 補正（固定、1候補だけ）
着順 m（1・2・3着）ごとに、6艇の多項ロジット：
  p'_m(i) ∝ exp( α_m · log p_m(i) + β_m · x_i )
- p_m(i) は保存済み rank_probabilities。α_m=1, β_m=0 なら元と同じ
- 学習データのラベルは m 着の艇。α_m, β_m（7個）を、評価日より前の対象レースだけで最尤推定。L2 正則化 λ=10（β と α−1 に、総和の負の対数尤度に 0.5·λ·‖·‖² を加える）
- 3連単：q'(i,j,k) ∝ p'_1(i)·p'_2(j)·p'_3(k)（i,j,k は相異なる）、上位6点。同点は組番順
- λ・特徴・式は結果を見て変えない

## 比較（同じレース）
- 基準1：保存済み baseline_picks（makeBets）
- 基準2：基準分布 q（= 保存済み baseline_distribution）の上位6点
- 補正：q' の上位6点
- 指標：LogLoss（q vs q'）、6点セットの予測確率合計と実際の的中率、6点の的中率、変更券数・変更R、基準だけ的中／補正だけ的中、日別の差、推定した係数の推移
- McNemar z は日内相関・複数比較を調整していない探索的な指標として記録

## 扱い
- 10/03〜10/22 は探索で何度も見た期間なので、未使用評価として扱わない
- 改善が見えても採用はしない。前向き検証にするなら、23日以降の未使用データで、この定義を変えずに別途事前登録する
