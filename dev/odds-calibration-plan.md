# 保存時オッズを使う確率補正の前向き検証

本番の予想・購入条件・投資履歴は変更しない。既存の通常V8・Expert比較、温度校正、期待値方式の保存記録も維持する。

## 補正候補

全120通りの締切前オッズがそろった記録だけを対象にする。取得から保存まで10分以内で、未来の取得時刻や締切後の保存は除外する。

市場の分布は各買い目の `1 / 保存時オッズ` を全120通りで正規化する。これは実際の的中確率を保証するものではない。通常V8の分布を温度 `1` または `0.75` のいずれかで調整し、市場の分布を `0 / 25 / 50 / 75%` 混ぜる。候補は計8通りで固定し、後から追加しない。

## 学習と固定

修復済み検証の最初の20日について、当日より前の日だけを学習に使用する。正しい締切前保存・確定結果・全120点オッズを持つ500レース以上が必要。学習期間の平均対数損失が最小の候補を選ぶ。同値なら市場の混合が少ない候補、その後は温度1を優先する。回収率で候補を選ばない。

学習時刻、20日分の日付、レース数、学習内容のSHA-256、選んだ係数、全候補の学習誤差を `dev/probability-calibration/odds-aware-v1.json` に一度だけ保存する。次回以降は保存済みの係数を使用し、追加の結果で再学習しない。形式不良の固定モデルはエラーにし、推測で置き換えない。

## 将来レースの比較

固定時刻より後で、かつ学習日の後のレースを締切前に保存するときだけ、別の仮想比較欄を追加する。終了済みのレースや既存保存記録への補正買い目の追加は禁止。

補正前・補正後は同じ保存時オッズと既存の期待値方針（確率割引0.75、最低期待値1.08、最大4点、各100円）を使用する。補正前の買い目は再生成せず、保存済みの通常V8側期待値買い目を使う。

同じ将来レース群で購入数・見送り数・的中率・回収率・仮想収支・対数損失・Brier誤差・最大累積下落を表示する。購入数が違う場合は的中率だけで優劣を判断しない。5日以上・150レース以上の比較後に人が確認し、自動採用や本番反映は行わない。

## 確認項目

- 20日・500レース未満では学習しない。
- 既存記録と固定モデルを変更しない。
- 締切後・固定前・学習日・古いオッズを使って比較買い目を作らない。
- 係数選びに後の検証結果を使わない。
- 返還・中止・対象外を成績に混ぜない。
- 補正により購入がゼロになる場合も、見送りとして別に集計する。

新しい補正は開発版の仮想検証に限定する。高配当側の過大評価という仮説が誤りの場合も、結果をそのまま残す。
