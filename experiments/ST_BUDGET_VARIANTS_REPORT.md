# 展示ST・点数減・厚張りの前向き比較

開発版の修復済み履歴コホートに `preclose-st-budget-v1` を追加。締切前に実際に保存できた予測から比較を開始し、締切後に新しい買い方を過去のレースへ後付けしない。本番の予測・買い目・実績は変更していない。

[開発検証画面](https://konyan3150-lgtm.github.io/kyotei-ai-v8-dev/validation.html) に「展示ST・買い方の比較」を追加。修復前の参考記録を選択した場合はこの比較を非表示にする。

| 展示STの重み | 条件 |
|---|---|
| 0 | 展示STの寄与なし |
| 12.5 | 標準の半分 |
| 25 | 固定エンジンと同じ標準条件 |
| 50 | 標準の2倍 |

6艇すべての展示STが数値・非負・2秒以内の時だけ、同じレースを4条件で比較。欠け・負の展示STは、この実験ではレース単位で対象外とし件数を表示する。展示タイム・周回・回り足・直線などの他の重み、固定エンジンの係数と上下限は維持。標準条件は元のスコアをそのまま使い、元の6点と厳密に一致する。

| 買い方 | 1レース600円の配分 |
|---|---|
| 6点均等 | 6点×100円 |
| 3点均等 | 上位3点×200円 |
| 2点均等 | 上位2点×300円 |
| 自信度が高い時に厚張り | スコア基準を満たす時に上位3点へ300/200/100円。その他は6点×100円 |

固定の自信度基準は1着スコア上位0.62以上・次位との差0.25以上。これは検証用の固定基準で、校正された的中確率や利益保証ではない。条件を見て後から閾値を調整しない。

各方式の投資は600円で統一し、的中した点の購入額に応じて公式の100円払戻しを掛け合わせる。6点と比べて的中率が下がる可能性と回収率の両方を見る。複数の方式を比較する探索的検証であり、最高成績の方式を自動で本番採用しない。
