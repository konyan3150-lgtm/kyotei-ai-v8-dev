# 保存時オッズと公式払戻の差を分離する診断

2026-10-09。開発版の収集レポートに `odds_deterioration` を追加。
既存の締切前スナップショットと公式結果だけを読む。新しい予想や買い目は過去レースに作らない。

対象は修復済みコホートで、正しい締切前時刻、完全な120通りの保存オッズ、10分以内のオッズ鮮度、正常な結果が確認できるレース。
取消・除外・未確定結果・不正な入力を除く。保存済み6点各100円と、保存済み期待値候補を別集計する。
期待値候補は確率・オッズ・投資額が保存時の入力と一致するものだけを使う。

各集計で、次を同じ投資額で比較する。

1. 推定払戻：保存確率×保存オッズ×保存投資額の合計。
2. 保存オッズでの的中払戻：実際に当たった券の保存オッズ×保存投資額の合計。
3. 実際の払戻：公式100円払戻×保存投資額÷100の合計。

「3−2」は的中券の払戻変動による差。「2−1」は確率誤差・選択・標本のばらつきが混在する残差。
この二つを回収率のポイント差で表すと、実績回収率と推定回収率の差に一致する。
保存時のオッズで投票できても、そのオッズが確定するという意味ではない。2は診断用の仮定。

当たった組合せの `公式払戻÷100÷保存オッズ` の中央値、10/90パーセンタイル、下落件数も出す。
負けた組合せの最終オッズは払戻から復元できない。そのため、当たり券だけの比率で全券の下落率を決めたり、利益が出ると断定したりしない。
日別の同じ集計と、最大払戻をゼロにして元の投資額をすべて残したストレス回収率も出す。

## 検証

単位換算、差の恒等式、見送り、外れ時の欠損、最大払戻のストレス、入力の不変性を確認。
期限後・古いオッズ・不正結果・取消/除外・不完全オッズ・改変した期待値券の除外もテスト。
既存の保存オッズ診断・確率補正のテストと、収集処理のJS構文検査も通過。

本番、既存買い目、金額、履歴、予想ルールは変更しない。回収率改善の確認や本番採用は今回の診断追加と別。
次は実データの差を確認し、確率補正・オッズ変動・購入条件のうち優先して検証するものを決める。

## 実データへの適用結果

GitHub Actionsのテスト、前日までの履歴更新、直近成績の生成も成功。収集ジョブはその時点で3回の限定収集を実行中だった。

最大的中への依存も採否の評価に含める。6日間の結果だけで投資額を増やす根拠にはしない。
